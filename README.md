# RSVP Alyn & Syarifuddin

Jemputan perkahwinan pada 12 Disember 2026 di Asiana Grand Hall Cheras.

Fail index.html mengandungi HTML, CSS dan JavaScript lengkap. Folder assets mengandungi lagu, fon dan fail kalendar yang sama seperti laman asal.

## Terbitkan

Di Settings → Pages, pilih Deploy from a branch → main → /(root) → Save.

## Backend

Gunakan Code-GitHub.gs daripada pakej untuk mengemas kini projek Google Apps Script dan terbitkan New version pada deployment Web App anda. URL backend dikonfigurasi pada nilai SCRIPT_URL dalam index.html.

Kandungan laman, gaya, bunga, lagu, peta dan fungsi RSVP dikekalkan. Backend Google Sheets perlu aktif untuk menyimpan kehadiran dan memaparkan ucapan.
